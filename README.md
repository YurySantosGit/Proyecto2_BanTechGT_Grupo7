## Descripción

Este repositorio contiene el desarrollo del Proyecto 2 de Redes de Computadoras 1:

**Infraestructura Financiera y Alta Disponibilidad BanTech GT**

El proyecto consiste en diseñar e implementar una infraestructura de red multisede utilizando tecnologías de Capa 2 y Capa 3, enrutamiento dinámico, alta disponibilidad y mecanismos de redundancia.

---

## Tecnologías principales

- VLAN
- VTP
- Trunking 802.1Q
- Router-on-a-Stick
- Inter-VLAN Routing
- RIPv2
- EIGRP
- OSPF
- Rutas estáticas
- Redistribución de rutas
- Rapid PVST+
- EtherChannel
- LACP
- HSRP
- VLSM
- Cisco Packet Tracer
